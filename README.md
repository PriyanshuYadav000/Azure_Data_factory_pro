# Azure_Data_Factory_Pro

## 📌 Project Overview

Azure_Data_Factory_Pro is an end-to-end ETL project built using **Azure Data Factory (ADF)**. The project automates data ingestion from REST APIs, performs dynamic transformations and validations, and loads processed data into Azure SQL Database and Azure Storage. It also demonstrates enterprise-level concepts such as incremental loading, parameterized pipelines, Logic Apps integration, and GitHub-based CI/CD.

## ⚙️ Pipeline Workflow

1. Extract data from REST APIs.
2. Perform incremental loading using watermark tables.
3. Apply dynamic pipeline parameters.
4. Transform and validate data using Mapping Data Flows.
5. Load processed data into Azure SQL Database and Azure Storage.
6. Trigger Logic Apps for pipeline success or failure notifications.
7. Maintain source control using GitHub and CI/CD deployment.
